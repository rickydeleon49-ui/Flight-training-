# [WITHDRAWN] Her Flight Deck 0.5.2 — Release Notes

> [!WARNING]
> **WITHDRAWN RELEASE:** Version `0.5.2` was prepared and withdrawn on 14 September 2026 due to an unresolved detection (`Trojan:Win32/Wacatac.B!ml`) by Microsoft Defender on the Windows installer.
> In accordance with repository engineering rules and `scripts/release-policy.json`, version `0.5.2` is **permanently retired and must never be distributed or reused**.
> The latest distributable release remains `v0.5.1`. The features below will be released in `v0.5.3` or later after all verification gates pass.

---

### What was prepared for 0.5.2 (Deferred to 0.5.3+)

- Large Study Libraries open in smaller batches, with search and filters still covering every item.
- Imported documents stay in the app's own storage. PDF Open and folder-reveal permissions were tightened for desktop use.
- Large PDFs can be divided automatically into labeled study-size parts, or manually by page range. Each part has its own study material and guide.
- Gemini can create a practice test alongside study guides and flashcards from the selected document.
- Backup and restore checks are stronger, and long document and backup operations keep the app window more responsive.

Before installing over an existing copy, save a complete backup from Settings. Keep that file somewhere safe until the updated library and documents have been checked.
