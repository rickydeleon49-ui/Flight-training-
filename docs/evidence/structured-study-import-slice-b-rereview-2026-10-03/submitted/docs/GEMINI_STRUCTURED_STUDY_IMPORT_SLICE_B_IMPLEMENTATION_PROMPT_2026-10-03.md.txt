### Phase 2: Native SQLite atomic command
1. In `src-tauri/src/study_packet.rs`:
   - Define Rust DTO `StructuredImportSaveOperation` (matching camelCase JSON with unknown field denial):
     ```rust
     #[derive(Debug, Clone, Deserialize)]
     #[serde(rename_all = "camelCase", deny_unknown_fields)]
     pub struct StructuredImportSaveOperation {
         pub operation_id: String,
         pub material_id: String,
         pub content_hash: String,
         pub material: ImportedMaterialDraft,
         pub study_set: Option<ImportedStudySetDraft>,
         pub practice_test: Option<ImportedPracticeTestDraft>,
     }
     ```
   - Define typed success and error return shapes:
     ```rust
     #[derive(Debug, Clone, PartialEq, Eq, Serialize)]
     #[serde(tag = "status", rename_all = "snake_case")]
     pub enum StructuredImportSaveResult {
         Saved { material_id: String },
         AlreadySaved { material_id: String },
     }

     #[derive(Debug, Clone, PartialEq, Eq, Serialize)]
     #[serde(rename_all = "camelCase")]
     pub struct NativeImportSaveFailure {
         pub code: &'static str,
         pub message: &'static str,
     }
     ```
   - Implement `save_structured_study_import(app: AppHandle, op: StructuredImportSaveOperation) -> Result<StructuredImportSaveResult, NativeImportSaveFailure>`:
     - Execute off the UI thread via `tauri::async_runtime::spawn_blocking`.
     - Open pinned `Connection::open(&db_path)`.
     - Configure `connection.busy_timeout(Duration::from_secs(5))` and `connection.pragma_update(None, "foreign_keys", "ON")`.
     - Start transaction with `connection.transaction_with_behavior(TransactionBehavior::Immediate)`.
     - **Defensive revalidation:**
       * `op.operation_id` and `op.material_id` are valid UUID v4; `op.operation_id == op.material_id`.
       * `op.content_hash` matches `^[0-9a-f]{64}$`.
       * `material.title` is non-empty and 1–200 code points.
       * At least one substantive component: non-empty study set or test with ≥1 question.
       * If `study_set` present: summary ≤ 20,000 code points, sections ≤ 100, flashcards ≤ 500, all flashcards have `source_page: None`, `provider == "import"`, `model == ""`, `title == material.title`. Non-empty `source_notes` requires substantive guide/cards.
       * If `practice_test` present: questions 1–200, each question has 2–6 options, `correct_index < options.len()`, `source_page: None`, `provider == "import"`, `model == ""`, `title == material.title`.
     - **Idempotency check (Inspecting actual stored content):**
       * If row with `id = op.material_id` exists in `study_materials`:
         - Compare existing stored title with `op.material.title`. If different -> return conflict error.
         - Compare nullable presence and all stored fields in `ai_study_sets` and `practice_tests`.
         - If all stored content matches payload: commit transaction and return `Ok(StructuredImportSaveResult::AlreadySaved { material_id })`.
         - If any stored content differs (or forged hash sent): return conflict error.
     - **Insert statements:**
       * Insert into `study_materials` (id, title, material_type='study_guide', topic='general', review_status='needs_review', priority='later', created_at=now, updated_at=now, notes='', file_path=NULL).
       * If `study_set` is present: insert into `ai_study_sets` (source_material_id, title, summary, sections_json, flashcards_json, source_notes, provider='import', model='', generated_at=now, updated_at=now).
       * If `practice_test` is present: insert into `practice_tests` (source_material_id, title, questions_json, provider='import', model='', generated_at=now, updated_at=now).
     - Commit transaction and return `Ok(StructuredImportSaveResult::Saved { material_id })`.
2. In `src-tauri/src/lib.rs`:

   - Implement `saveStructuredImportAtomically` with observable throwing flush and snapshot recovery:
     * Serialize execution via `saveMutex`.
     * Capture pre-operation snapshot: `const preOpSnapshot = cell.current.export()`.
     * `cell.current.run("BEGIN IMMEDIATE")`.
     * Execute insert statements.
     * `cell.current.run("COMMIT")`.
     * Call `persistDurable(cell.current)`.
     * If `persistDurable` throws (export or storage failure):
       - Catch error.
       - Revert in-memory handle: `cell.current.close()`, `cell.current = new SQL.Database(preOpSnapshot)`.
