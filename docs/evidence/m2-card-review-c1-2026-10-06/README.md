## What this establishes and what it doesn't

- **Established in source:** the approved defaults on the native rusqlite path and on both single-connection drivers with real transactions; generation-protected reset including the reset race, replay after reopen, tombstone skipping and isolation; rollback by real SQL failure injection natively and storage-refusal recovery in the browser; identical validator outcomes on three engines; the UI recovery rules in jsdom with the real provider.
- **Not established:** installed macOS behavior, VoiceOver, signing, packaging or release; the Tauri SQL plugin's read path (its SQL is the same text the native test runs). No real profile, provider, Gemini call or network was used anywhere.
- The "two active versions" fixture case is refused by the unique-index comparison first, because such rows cannot exist while the registered index does.
