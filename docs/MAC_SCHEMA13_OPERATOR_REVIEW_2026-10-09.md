## MACV-R7 — Finish operator permissions, restoration and path/account policy [P1]

**References:** `hfd-operator.sh:28–34,58–69,109–132,135–160`; `env.sh`; runbook §§1.4,2–5. All refer to the submitted `docs/evidence/mac-schema13-helper-corrections-2026-10-08/` files.

1. **The real staged output roots are not writable by the approved user.** Read-only stat/ACL inspection shows the kit, `evidence/` and `profiles/` owned by uid501 (`rickymac`), mode0755, without a write-grant ACL. `hfdtest` is uid502. The runbook's first run-folder creation and later profile copies cannot write there. The kit's parent being `/Users/Shared` does not make these child directories writable. Preserve the readable kit as immutable inputs; create an explicit per-user task workspace owned by hfdtest for evidence/profile snapshots, and make env/script/runbook agree on it. Do not solve this with blanket world-writable permissions or unreviewed ownership changes to existing inputs.
2. **Unblock always breaks on the actual path with spaces.** The mode record is one line `path mode`, but `read -r dir mode` splits `/Users/hfdtest/Library/Application Support/...` at its first space. The scratch diagnostic with the same spaced-path shape reproduces exit2; after a successful block, the directory remains mode0500 instead of its original0700. Use an unambiguous versioned record and parse it safely. Restore the exact recorded mode, not just `chmod u+w`; bind it to the intended directory/current run, and support repeat recovery without guessing the latest unrelated record. Preserve restoration on normal completion and aborted failure checks.
3. **Account inspection errors are treated as a standard account.** `dseditgroup ... && die ... || true` accepts exit2 as if it meant “not a member.” With a controlled membership error and the correct UID mapping, a copy succeeds (exit0). Classify account results explicitly and fail closed, consistent with the corrected helper. Apply the policy to every mutating command, not just operands that literally equal the approved-root string.
4. **String prefixes allow filesystem escapes.** An operand `profiles/../outside` is accepted; a destination whose parent is `profiles/link` pointing outside is also accepted and written through. Both diagnostics prove the copy occurred outside the advertised profiles policy, solely within disposable test directories. Validate canonical source/destination-parent containment, reject symlink components/dangling existing targets and self-nesting, and refuse existing destinations before mutation. Keep source/destination intact on refusal and preserve task-owned recovery if copying fails. Fixed policies must be production logic with controlled scratch tests, not weaker test-only replacements of path checks.

The current15 cases never perform a positive block→unblock roundtrip under controlled lane facts, so their pass does not prove the restoration code. Add those controls, spaces, exact mode/abort recovery, account errors, traversal/symlink refusals and per-user writable workspace tests. Any internal test redirection must be unavailable through operator CLI flags.

**Walkthrough corrections in the same task:** explicitly relaunch OLD after A.2's quit before A.3's UI work; make mount/install operations refuse existing app destinations and verify the mounted candidate instead of assuming the fixed `/Volumes/Her Flight Deck` path; record a successful retry after the intentional backup failure (the current section proves only the abort).
