**Visibility.** The repository is private, so the release is visible only to people with repository access. Making the repository public is a separate decision that has not been taken.

## Findings during release preparation

**CI test race, fixed in this PR (test only).**

- **What happened:** `MaterialDetailImport.test.ts` clicked "Regenerate" with `getByRole` before the mocked Gemini status read had resolved. It failed intermittently in CI (run 38862624752).
- **Reproduced:** delaying the mock by 50 ms makes it fail every time.
- **Fix:** `findByRole` waits for the button. No production change, and the released bytes are unaffected.

**An older app opened the owner's real library.**

- **What happened:** at 23:23 PDT on 15 October, before the 0.5.3 app was moved out of `/Applications`, version 0.5.3 opened the owner's schema-14 library. It wrote `last-run-version.txt` = 0.5.3 and made a `2026-10-16-062329-before-0.5.3` safety copy.
- **Data check (read-only):**
  - the database file was not modified (mtime 20:56);
  - `integrity_check` is ok, and migrations 1–14 are present;
  - its logical content (42 tables, 137 rows) is identical to that safety copy.
- **Effect:** no data change. The next 0.5.4 launch will simply see a version change and make another safety copy.
- **Action:** the release notes now tell users to stop using older copies. Older binaries cannot be fixed retroactively.
