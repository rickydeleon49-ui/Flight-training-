## The student experience

She has not enrolled yet. A school, instructor, lesson, aircraft and Gemini account remain optional.
“Connected topics” means finding the few things she already saved about something she is studying, then opening one.
For example, from a crosswind material: her guide section, its cards, a saved missed-question review,
a question she wants to ask and a lesson she deliberately linked. These are navigation choices, not a course or proficiency report.
**Smallest useful first slice:** one collapsed **Related study** list on an existing material page, beside its existing navigation.
Reuse the current guide/card jump controls there; do not add a second row of duplicate buttons or a new Hub destination.
Show three rows initially, **Show more** up to five; at most one row per kind, in guide/cards/saved review/questions/lesson order.
Rows name their destination and reason: “From this material”, “Linked by you” or, in a later slice, “Same ACS tag: …”.
An umbrella “Cards” row includes existing picture cards; oral practice stays in its existing material section, without another practice screen.
Only show rows with saved content. Offer no generation buttons or “missing study” checklist; empty copy: “Nothing linked here yet.”
If a row read fails, say it could not be checked; never present failure as no saved content. Full existing history/search remain available.
Linked Questions need no named instructor; clicking opens the exact question. Linked lessons open existing preparation, not a new checklist.
No automatic completion, review rating, scheduling, score, proficiency inference or changed Daily Plan priority follows from opening a row.

Later, the existing topic filter or ACS lookup can reuse this list for multiple materials.
A broad topic such as Weather is a browsing filter; it does not mean every section/card supports the same proposition.
An ACS task view uses the catalog's explicit child codes and exact matching tags, never a string-prefix match or guessed skill mapping.
The first slice stays material-scoped so she gets value before organizing tags or taking a knowledge test.

**Grounded questions** means asking about selected documents and seeing what supports the reply, what is missing and what may differ.
Today's Ask Gemini already answers from one PDF or supplied study context, asks the model to acknowledge gaps and returns page numbers.
Do not sell citations or a second chat box as a new feature. Improve the same Ask Gemini surface only after the local list proves useful.
Example: “Does this crosswind guidance apply to this aircraft?” A reply should identify supporting passages,
say “Your selected source does not establish this aircraft's limit”, and leave an unresolved question for her to check with an instructor.
For two deliberately selected, different editions later: show each source's wording and applicability; never silently choose a winner.
Use one concise evidence note below the answer, with expandable source passages, rather than a grid of warnings or confidence badges.
Permanent wording: **“Study aid — check the sources and your instructor.”** A citation is not proof that an answer is correct.

**Do not build:** a dashboard, knowledge graph, topic editor, parallel library/search, new scheduler, mastery percentages,
automatic ACS tagging, automatic instructor feedback analysis, stored chat, whole-library AI indexing, embeddings, OCR, voice or embedded reader.
Notes remain free writing: do not categorize or mine them for links/prompts. Do not turn lesson/journal/financial data into AI context.
Rows 8–11 already own continuation, mistake review, offline packs, source links and correction/history work; retain their contracts.

## Risks and synthetic acceptance

Main risks: unrelated content looks authoritative, current edits overwrite historical meaning, wrong-edition citations and unintended private uploads.
Use only authored fictional profiles, tiny synthetic PDFs/PNG diagrams, invented scenarios, fixed clocks and loopback Gemini fixtures; no real files/keys.
Test exact-tag normalization, near-prefix rejection, archived/unresolved codes, task child-code boundaries, duplicate titles and multiple-material membership.
Cover no enrolment/lesson/instructor/key/history; newest-ten truncation, correct-only attempts, deleted tags/materials, undo, unavailable reads and late results.
Verify guide/card digest changes refuse stale destinations; old attempts still reveal only their frozen questions/answers/sources and never current replacements.
Prove list/navigation/reveal writes no scores, reviews, completion or schedule changes; oral answers stay ephemeral and picture-card identity stays intact.
Test changed/missing/same-name sources, source hashes, split offsets, physical/printed pages, addenda and backup/restore reconstruction without silent relinking.
Grounding fixtures cover unsupported claims, quote mismatch, invalid pages/source IDs, irrelevant snippets, scans/partial text, conflicting revisions,
aircraft variants/unknown applicability, mixed units, malicious source instructions, oversized/malformed replies, cancellation and out-of-order responses.
Treat document text as evidence, never instructions/tools; model output renders as inert text. No automatic URL fetching or actions from an answer.
Assert zero outbound calls for 02b/02c; for AI fixtures inspect the exact selected payload, native refusal gates and absence of Notes/journal/profile/financial data.
Check session content is absent from persistence/logs/exports/backups; test source switches, restore and cancellation with no late answer publication.
Walk keyboard/focus return, screen-reader announcements, narrow windows/200% text and 44px targets; keep the short list calm and useful before adding slices.
